CSV Schema Guide

Your CSV file must include a type column to distinguish between supply and demand rows.

Supply Rows

Use type = supply and include the following columns:

  • type – must be supply
  • crop_type – e.g., tomato, onion
  • quantity_kg – positive number
  • lat – latitude (-90 to 90)
  • lon – longitude (-180 to 180)
  • location_label – optional display text
  • spoilage_time – e.g., +48h or ISO datetime
Demand Rows

Use type = demand and include the following columns:

  • type – must be demand
  • crop_type – e.g., tomato, onion
  • quantity_kg – positive number
  • lat – latitude (-90 to 90)
  • lon – longitude (-180 to 180)
  • location_label – optional display text
  • min_shelf_life_h – positive number (hours)
Rows with missing or invalid data will be skipped. A summary will appear after import.
